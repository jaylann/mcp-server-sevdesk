# Glossar

sevDesk, die deutsche Buchhaltung und dieser Server haben jeweils ihre eigenen Wörter, und die
Werkzeuge mischen Deutsch und Englisch. Diese Seite ordnet den deutschen Begriffen die englischen
zu, die in den Werkzeugen und ihren Beschreibungen vorkommen, mit einer kurzen Bedeutung und wo
jeder Begriff wichtig ist. Die Begriffe des Servers selbst stehen am Ende.

## Begriffe des Servers

| Begriff                                       | Bedeutung                                                                                                                  | Wo                                                        |
| --------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| Stufe (tier)                                  | Was ein Werkzeug darf: `read`, `write`, `commit` (bindend, fragt dich) oder `external` (erreicht Dritte, fragt dich).      | [Berechtigungen](permissions.de.md#stufen)                |
| Werkzeuggruppe (toolset)                      | Eine Gruppe von Werkzeugen für einen Bereich, etwa `invoices` oder `reports`; `SEVDESK_TOOLSETS` wählt sie aus.            | [Konfiguration](configuration.de.md#werkzeuggruppen)      |
| Probelauf (dry run)                           | Ein Schreibvorgang, der jede Prüfung ausführt und seine Vorschau zurückgibt, ohne etwas zu senden.                         | [Berechtigungen](permissions.de.md#probelauf)             |
| Vorschau (preview)                            | Was ein Schreibvorgang tun würde, gebaut aus dem, was das Werkzeug gerade gelesen hat: Aktion, Angaben, Warnungen.         | [Bestätigung](security/confirmation.de.md)                |
| Bestätigung (confirmation)                    | Deine Freigabe eines Aufrufs der Stufe `commit` oder `external`, im Client (`elicit`) oder auf einer Webseite (`browser`). | [Bestätigungsarten](permissions.de.md#bestätigungsarten)  |
| Freigabe-Postfach (approval inbox)            | Die Seite eines entfernten Servers, auf der Freigaben auf dich warten.                                                     | [Freigaben](remote/approvals.de.md)                       |
| Referenzcode (reference code)                 | Der kurze Code, der eine Freigabe im Browser dem Ergebnis des Werkzeugs zuordnet.                                          | [Bestätigungsarten](permissions.de.md#bestätigungsarten)  |
| Audit-Log (audit log)                         | Ein optionales lokales Log jedes Schreibvorgangs: Vorschauen, Freigaben, Ausführungen.                                     | [Audit-Log](permissions/audit-log.de.md)                  |
| Profil (profile)                              | Eine benannte Einrichtung in der Profildatei (Token-Quelle, Stufen, Ordner), ausgewählt mit `SEVDESK_PROFILE`.             | [Profile](configuration/profiles.de.md)                   |
| Bezeichnung im Schlüsselbund (keychain label) | Der Name, unter dem `token set` ein Token im Schlüsselbund des Betriebssystems ablegt.                                     | [Profile und Schlüsselbund](configuration/profiles.de.md) |
| Zugang (grant)                                | Im OAuth-Fernzugriff: eine freigegebene Verbindung eines Clients zu einem sevDesk-Konto, mit ihren Stufen.                 | [Fernzugriff](remote.de.md#stufen-je-zugang)              |
| Prompt                                        | Ein fertiger Ablauf wie `month_end_close`; er erzeugt nur Text, die Arbeit machen die Werkzeuge.                           | [Prompts](tools.md#prompts)                               |
| stdio, Fernzugriff (remote mode)              | Der Server, den dein Client auf deinem Computer startet, oder den du selbst über HTTP betreibst.                           | [Fernzugriff](remote.de.md)                               |
