# Glossary

sevDesk, German bookkeeping and this server each have their own words, and the tools mix German and
English. This page maps the German terms to the English ones the docs and tools use, with a
one-line meaning and where each matters. The server's own terms are at the end.

## Documents

| German                             | English                         | Meaning                                                                                                   | Where                                                                                                                |
| ---------------------------------- | ------------------------------- | --------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| Rechnung (RE)                      | invoice                         | An outgoing invoice to a customer.                                                                        | `sevdesk_invoice_*`, [Invoices guide](guides/invoices.md)                                                            |
| Rechnungsentwurf                   | draft invoice                   | An invoice before it is finalized: no number, freely changeable.                                          | [`sevdesk_invoice_create_draft`](tools.md#sevdesk_invoice_create_draft)                                              |
| Abschlags-, Teil-, Schlussrechnung | advance, partial, final invoice | Invoices for part of an order (types AR, TR, ER).                                                         | [`sevdesk_invoice_create_from_order`](tools.md#sevdesk_invoice_create_from_order)                                    |
| Stornorechnung (SR)                | cancellation invoice            | The negated copy sevDesk creates when an invoice is cancelled.                                            | [`sevdesk_invoice_cancel`](tools.md#sevdesk_invoice_cancel)                                                          |
| Mahnung, Zahlungserinnerung (MA)   | payment reminder                | A reminder for an overdue invoice, itself an invoice of type MA.                                          | [`sevdesk_invoice_create_reminder`](tools.md#sevdesk_invoice_create_reminder), [`dunning_run`](tools.md#dunning_run) |
| Mahnlauf                           | dunning run                     | Going through all overdue invoices and reminding the customers.                                           | [`dunning_run`](tools.md#dunning_run)                                                                                |
| Gutschrift, Rechnungskorrektur     | credit note                     | A document that reduces or refunds an issued invoice, or a commission credit (Provisionsgutschrift).      | `sevdesk_credit_note_*`, [Correcting an invoice](guides/invoices.md#cancel-or-correct)                               |
| Angebot (AN)                       | offer, quote                    | An offer to a customer; one of the three order types.                                                     | [`sevdesk_order_create_draft`](tools.md#sevdesk_order_create_draft)                                                  |
| Auftragsbestätigung (AB)           | order confirmation              | Confirms an accepted order; one of the three order types.                                                 | `sevdesk_order_*`                                                                                                    |
| Lieferschein (LI)                  | delivery note                   | Goes with a delivery; one of the three order types.                                                       | `sevdesk_order_*`                                                                                                    |
| Auftrag                            | order                           | The tools' collective word for offers, order confirmations and delivery notes.                            | [Toolset `orders`](tools.md#toolset-orders)                                                                          |
| Beleg                              | voucher                         | A receipt or supplier invoice (Ausgabe) or another income document (Einnahme), booked on accounts.        | `sevdesk_voucher_*`, [Receipts guide](guides/receipts.md)                                                            |
| Belegbild                          | receipt file                    | The scan, PDF or e-invoice file attached to a voucher.                                                    | [`sevdesk_voucher_receipt_save`](tools.md#sevdesk_voucher_receipt_save)                                              |
| Belegnummer                        | voucher number                  | The receipt's or supplier invoice's own number, used for duplicate checks.                                | [`sevdesk_vouchers_list`](tools.md#sevdesk_vouchers_list)                                                            |
| Position                           | position, line                  | One line of a document: name, quantity, price, tax rate.                                                  | every draft tool                                                                                                     |
| Tag, Schlagwort                    | tag                             | A name that groups invoices, credit notes, orders and vouchers, e.g. by project, customer or branch.      | [`sevdesk_tags_list`](tools.md#sevdesk_tags_list), [`sevdesk_document_tag`](tools.md#sevdesk_document_tag)           |
| E-Rechnung                         | e-invoice                       | A structured invoice under EN 16931 that software can read; required between German businesses over time. | [Import](guides/receipts.md#import-an-e-invoice), [readiness check](guides/invoices.md#e-invoice-readiness)          |
| XRechnung                          | XRechnung                       | The German EN 16931 profile: pure XML (UBL or CII).                                                       | [`sevdesk_einvoice_parse`](tools.md#sevdesk_einvoice_parse), [`sevdesk_invoice_xml`](tools.md#sevdesk_invoice_xml)   |
| ZUGFeRD, Factur-X                  | ZUGFeRD, Factur-X               | A PDF with the invoice XML embedded; the XML is what counts.                                              | [`sevdesk_voucher_import_einvoice`](tools.md#sevdesk_voucher_import_einvoice)                                        |
| Leitweg-ID                         | buyer reference                 | The address of a public-sector buyer for e-invoices.                                                      | [`sevdesk_contact_update`](tools.md#sevdesk_contact_update)                                                          |

## Document lifecycle

| German                      | English           | Meaning                                                                                       | Where                                                                                                                            |
| --------------------------- | ----------------- | --------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| fertigstellen, finalisieren | finalize          | Draft to open: sevDesk assigns the number and books it; legally binding.                      | [`sevdesk_invoice_finalize`](tools.md#sevdesk_invoice_finalize), [`sevdesk_order_finalize`](tools.md#sevdesk_order_finalize)     |
| Beleg verbuchen             | finalize voucher  | Voucher draft to open, so it counts in the profit and loss and the VAT return.                | [`sevdesk_voucher_finalize`](tools.md#sevdesk_voucher_finalize)                                                                  |
| versenden                   | send              | Email a document through sevDesk; it is then marked as sent.                                  | [`sevdesk_invoice_send_email`](tools.md#sevdesk_invoice_send_email)                                                              |
| stornieren, Storno          | cancel            | Void an open, unpaid invoice with a cancellation invoice; both stay in the books.             | [`sevdesk_invoice_cancel`](tools.md#sevdesk_invoice_cancel)                                                                      |
| zurücksetzen                | reset             | One step back: paid to open (payments unlinked), or open to draft.                            | [`sevdesk_invoice_reset`](tools.md#sevdesk_invoice_reset), [`sevdesk_voucher_reset`](tools.md#sevdesk_voucher_reset)             |
| festschreiben               | enshrine          | Lock a finalized document permanently (GoBD). Irreversible.                                   | [`sevdesk_invoice_enshrine`](tools.md#sevdesk_invoice_enshrine), [`sevdesk_voucher_enshrine`](tools.md#sevdesk_voucher_enshrine) |
| Entwurf, offen, bezahlt     | draft, open, paid | The main statuses; partially paid and, for vouchers, transferred (überwiesen) sit in between. | `status` filter of the list tools                                                                                                |

## Tax and bookkeeping

| German                               | English                            | Meaning                                                                                           | Where                                                                                          |
| ------------------------------------ | ---------------------------------- | ------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| Steuerregel                          | tax rule                           | How a document is treated for VAT (Update 2.0), e.g. 1 domestic revenue, 9 deductible expense.    | [`sevdesk_reference_lookup`](tools.md#sevdesk_reference_lookup) (`tax_rules`)                  |
| Steuersatz                           | tax rate                           | The VAT rate of a position: 0, 7 or 19 % in Germany; the tax rule decides which are allowed.      | every draft tool                                                                               |
| Kleinunternehmer (§ 19 UStG)         | small business                     | A business that charges no VAT and deducts none; tax rules 11 (sales) and 10 (expenses).          | [`sevdesk_account_info`](tools.md#sevdesk_account_info)                                        |
| Umsatzsteuer, Vorsteuer              | output VAT, input VAT              | VAT charged on sales, and VAT paid on purchases that can be deducted.                             | [Reports guide](guides/evaluations.md#vat-summary)                                             |
| Reverse Charge (§ 13b UStG)          | reverse charge                     | The customer, not the supplier, owes the VAT.                                                     | tax rules 5, 12–14, 21                                                                         |
| Umsatzsteuer-Voranmeldung (UStVA)    | VAT pre-return                     | The monthly or quarterly VAT return to the tax office.                                            | [`sevdesk_vat_summary`](tools.md#sevdesk_vat_summary), [`vat_precheck`](tools.md#vat_precheck) |
| Kennzahl (Kz)                        | form line                          | A numbered field of the UStVA form, e.g. Kz 81 or Kz 83.                                          | [`sevdesk_vat_summary`](tools.md#sevdesk_vat_summary)                                          |
| Zusammenfassende Meldung (ZM)        | EC sales list                      | The report of intra-EU supplies and services per buyer VAT ID.                                    | [`sevdesk_vat_summary`](tools.md#sevdesk_vat_summary)                                          |
| Soll-, Istversteuerung               | accrual, cash basis                | VAT due when invoiced, or when paid.                                                              | `basis` of the tax reports                                                                     |
| Einnahmenüberschussrechnung (EÜR)    | profit and loss (cash method)      | Income minus expenses, the profit statement of small businesses.                                  | [`sevdesk_profit_and_loss`](tools.md#sevdesk_profit_and_loss)                                  |
| Buchungskonto, Kontenrahmen SKR03/04 | booking account, chart of accounts | The account a voucher position is booked on, from the account's chart of accounts.                | [Receipts guide](guides/receipts.md#pick-the-booking-account-and-tax-rule)                     |
| Kontierungshilfe                     | receipt guidance                   | sevDesk's list of which booking account allows which tax rules and rates.                         | [`sevdesk_reference_lookup`](tools.md#sevdesk_reference_lookup) (`receipt_guidance`)           |
| DATEV, Buchungsstapel                | DATEV booking data                 | The export format German tax advisers import.                                                     | [`sevdesk_datev_export`](tools.md#sevdesk_datev_export)                                        |
| Steuerberater                        | tax adviser                        | Gives the binding answers; nothing the server says is tax advice.                                 | [Reports guide](guides/evaluations.md)                                                         |
| GoBD                                 | GoBD                               | The tax administration's rules for electronic books: booked records stay traceable and unchanged. | enshrine tools, [Invoices guide](guides/invoices.md#enshrine)                                  |
| Update 2.0                           | bookkeeping system 2.0             | sevDesk's current bookkeeping system, with tax rules and DATEV accounts; voucher writes need it.  | [`sevdesk_account_info`](tools.md#sevdesk_account_info)                                        |

## Server terms

| Term               | Meaning                                                                                                            | Where                                                   |
| ------------------ | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------- |
| tier               | What a tool may do: `read`, `write`, `commit` (binding, asks you) or `external` (reaches third parties, asks you). | [Permissions](permissions.md#tiers)                     |
| toolset            | A group of tools for one area, such as `invoices` or `reports`; `SEVDESK_TOOLSETS` picks them.                     | [Configuration](configuration.md#toolsets)              |
| dry run            | A write that runs every check and returns its preview without sending anything.                                    | [Permissions](permissions.md#dry-run)                   |
| preview            | What a write would do, built from what the tool just read: action, facts, warnings.                                | [Confirmation](security/confirmation.md)                |
| confirmation       | Your approval of a `commit` or `external` call, in the client (`elicit`) or on a web page (`browser`).             | [Confirmation modes](permissions.md#confirmation-modes) |
| approval inbox     | The page of a remote server where approvals wait for you.                                                          | [Approvals](remote/approvals.md)                        |
| reference code     | The short code that matches a browser approval to the tool result.                                                 | [Confirmation modes](permissions.md#confirmation-modes) |
| audit log          | An optional local log of every write: previews, approvals, executions.                                             | [Audit log](permissions/audit-log.md)                   |
| profile            | A named setup in the profiles file (token source, tiers, folders), picked with `SEVDESK_PROFILE`.                  | [Profiles](configuration/profiles.md)                   |
| keychain label     | The name under which `token set` stores a token in the OS keychain.                                                | [Profiles and keychain](configuration/profiles.md)      |
| grant              | In OAuth remote mode: one approved connection of a client to one sevDesk account, with its tiers.                  | [Remote mode](remote.md#tiers-per-grant)                |
| prompt             | A ready-made workflow such as `month_end_close`; it only produces text, the tools do the work.                     | [Prompts](tools.md#prompts)                             |
| stdio, remote mode | The server started by your client on your computer, or hosted by you over HTTP.                                    | [Remote mode](remote.md)                                |
